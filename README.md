## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

To access from mobile devices on the same Wi-Fi network:
```bash
npm run dev:host
```

---

## Key Features & Architecture

* **Dual Theme Engine**: One-click toggle between **Obsidian Dark Luxury** and **Swiss Paper White** (editorial high-contrast craft).
* **Tactile Micro-Audio**: Zero-dependency Web Audio API synthesizer for mechanical clicks, switch tones, and chime cues (`SOUND: ON/OFF`).
* **Real Founder Portraits**: Integrated high-resolution photography for both Teja and Lokesh Y.
* **100% Self-Hosted Assets**: All images, logo vector studies, 31 archival posters, and PDF brand presentations are hosted locally in `/public`.
* **Integrated Brand Identity Case Studies**: Direct modal presentations and PDF downloads for **The Rore Club**, **Suzen**, **CMC Global**, **MAXIFY**, **Bluebird (BB)**, **BBC Culture**, and the **LX Geometric Signature**.
* **31 Archival Posters**: Filterable mosaic grid with full-screen lightbox and keyboard navigation (`←`, `→`, `Esc`).
* **Interactive Commission Configurator**: Clients select disciplines (*Website Design*, *Brand Identity*, *Art Direction*, *Retainer*) and choose whether to message Teja, Lokesh, or both founders with dynamically formatted WhatsApp and Email inquiries.
* **Production Ready**: Verified with Next.js 15 static prerendering and full TypeScript safety.
